# 日期模型

## 原则

不能用“周一、周二……周日”作为日期事实，也不能只从周期 ID 反推每日日期。

每条记录至少保存：

- `period_start`：真实周开始日期，格式 `YYYY-MM-DD`
- `period_end`：真实周结束日期，格式 `YYYY-MM-DD`
- `period_id`：由起止日期派生的检索/去重标识，不是唯一事实来源
- `daily.date`：每天真实业务日期，格式 `YYYY-MM-DD`
- `weekday_label`：由 `daily.date` 派生的显示标签，例如“周六”

当前日明细的客流字段表示门店客流表中的“场域客流”；周经营中的“接待客流”继续保持周维度，不能按比例拆成每日接待客流。

## 为什么要这样做

以后如果需要做节假日、跨月、跨年、调班、补录、周环比、日趋势或时间线分析，系统应该直接使用真实日期，而不是重新猜测“周一”对应哪一天。

页面当前将真实日期和星期标签同时显示；星期标签只用于阅读，不能作为主键或计算依据。

## Excel / 飞书表的落地要求

底层表应把每日数据设计成“日期 × 门店 × 指标”的记录，而不是只保留 `周一` 到 `周日` 七个无日期列。若为了阅读保留七列，也必须额外保存对应的真实日期列，或由明确的周开始日期公式生成并校验。
