# 经营策略工作台 v1

## 产品位置

经营地图是首页和业务骨架。周数据负责事实录入，周报负责周期性刷新和复盘；两者都不是经营地图之外的独立信息源。

```text
周记录 / 飞书事实表
  -> 程序计算指标、变化、覆盖度与健康状态
  -> 经营地图节点
  -> 周报动态信号与因果调查
  -> 节点按需 AI 分析
  -> 长期经营机会
  -> 解决思路 / 打法
  -> 执行与验证结果
  -> 后续周期继续引用
```

## 三类更新节奏

### 每次读取都重新计算

- 当前指标和可比周期变化。
- 指标覆盖度和数据缺口。
- 节点健康、关注、预警状态。
- 当前周期与节点关联的周报信号数量。

这些内容完全由程序计算，不调用模型，也不保存重复经营事实。

### 按需调用 AI

- 节点当前经营解释。
- 动态信号的综合判断。
- 候选长期机会。
- 解决思路排序。

结果按 `周期 + 门店 + 节点 + 数据指纹` 缓存。数据未变化时直接复用；数据变化后标记过期，由人再次触发分析。外部模型与内测模拟器共用 `operating-node-analysis-v1` 契约。

### 跨周期长期保留

- 人工确认的长期经营机会。
- 稳定的解决思路和打法库。
- 打法来源、验证状态、适用场景和影响指标。
- 每次执行与验证结果。
- 已发布周报中的复盘结论和确认经验引用。

长期对象不随周报刷新而重建。模型只能提出更新候选，正式状态由人确认。

## 信息源边界

| 信息 | 权威来源 | 工作台处理 |
| --- | --- | --- |
| 经营数字 | 周记录与飞书事实表 | 只读取和计算 |
| 周度信号、调查、结论 | 周报分析对象 | 按经营节点引用 |
| 已确认经验 | 周报最终快照 | 按来源信号引用 |
| 长期机会 | 工作台长期状态 | 保留证据、优先级和状态 |
| 解决思路与打法 | 稳定策略目录 | 跨周期持续存在 |
| 执行结果 | 验证记录 | 回写打法状态和节点判断 |

## 第一版边界

- 没有会员、复购或购票转化直接数据时，页面明确显示缺口，不使用接待客流或销售票数冒充。
- 周报未完成时，调查中的动态信号可以展示，但不会自动升级为长期机会。
- 完整周报已经最终确认的结论，可以作为长期机会的初始来源。
- 单次打法结果只更新本企业验证状态；不能自动变成通用经验。
- 第一版保留最小验证记录，不建设复杂实验排期、权限和自动决策系统。
